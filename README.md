# 中国伟人图鉴 · Greats of China

三十四省，三千年底蕴——每个省区最值得记住的人物：帝王将相、文人墨客、实业家、科学家、当代巨匠。按八大区（华北/东北/华东/华中/华南/西南/西北/港澳台）浏览 34 个省级行政区，约 300 位人物，每人附朝代与一句话简介。

An atlas of the greats of every Chinese province — 34 regions, ~300 figures, from emperors and poets to scientists and founders.

## Stack

- Next.js 14 (App Router, `src/app`)
- 国风文卷设计：纸色底 + 墨字 + 印章红，Noto Serif SC / Ma Shan Zheng 书法字体
- 静态生成：34 个省区详情页 + 首页

## Features

- 34 省区 × 约 300 位伟人，全量双语元数据
- 八大区浏览分组，印章式省简称
- 每省"性格"一句话 + 人物朝代/领域标签
- SEO/GEO 元数据、OG 卡、Psyverse 统计
